# Vフレメーカー

VTuberさん向けの、フレーム（動フレ）に自分の立ち絵・動画を重ねて、静止画（PNG）と動画（MP4）を保存できるページです。
スマホでもパソコンでも、ブラウザだけで使えます。

公式のページはここだけです：https://kyonanimotion.github.io/vframe/

## 立ち絵は送りません
- 選んだ立ち絵・動画・素材は、その端末のブラウザの中だけで処理します。どこにも送らず、保存もしません。
- ページに通信の制限（Content-Security-Policy）を入れてあり、外のサーバーへの通信・外の部品の読み込みはできません。
- 外部のライブラリ・CDN・フォント・アクセス解析は使っていません（素の HTML・CSS・JavaScript だけ）。

## 重ね方
上から フレーム（いちばん手前）→ キャラ（まんなか）→ 背景（いちばんうしろ）。フレームと背景はなくてもよく、キャラは必ず入れます。

## Kyonの素材の形式（materials/）
フレームと背景は別々のファイルです。どの背景とどのフレームを組み合わせても使えます。

| 種類 | ファイル | 中身 |
|---|---|---|
| フレーム | `frame_34.mp4` | 3:4（基本）：1080×1440 のコマを横に2つ並べた 2160×1440：左＝色／右＝透け具合（白＝見える） |
| フレーム | `frame_v.mp4` | 1080×1920 のコマを横に2つ並べた 2160×1920：左＝色／右＝透け具合（白＝見える） |
| フレーム | `frame_h.mp4` | 1920×1080 のコマを縦に2つ並べた 1920×2160：上＝色／下＝透け具合 |
| フレーム | `fg_34.png` `fg_v.png` `fg_h.png` | 静止画の保存用（ストレートアルファの透過PNG） |
| 背景 | `bg_34.mp4` `bg_v.mp4` `bg_h.mp4` | 普通の MP4（1080×1440／1080×1920／1920×1080） |
| 背景 | `bg_34.png` `bg_v.png` `bg_h.png` | 静止画の保存用 |
| 共通 | `thumb.png` | 一覧の見本 |

- H.264（High）・yuv420p・30fps・音なし・faststart。つなぎ目の分からないループ。
- フレームの色は、透け具合を掛ける前の色（ストレート）。
- 前の形「背景｜色｜透け具合」の3コマ（3240×1920／1920×3240）も、手持ちの素材として読めます。
- お試しの素材の一覧は `materials/materials.js`（層ごとの配列）。
- ページのファイルと素材は `?v=数字` を付けて読みます。直したら数字を変えてください（古いファイルがブラウザに残らないように）。
